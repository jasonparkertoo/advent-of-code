// General Java conventions
Always use descriptive names for variables, methods, and classes; avoid single-letter abbreviations like "q" for "queue".
Follow standard Java camelCase conventions for method and variable names, and PascalCase for class names.
Ensure every class has a clear purpose and is well-documented using Javadoc comments.
Prefer using modern Java features (e.g., streams, optionals) where appropriate, avoiding older, less efficient constructs.
Always manage system resource with try-with-resources blocks.
Prefer immutability

// Error Handling
Always handle errors gracefully. Use `try-catch` blocks for checked exceptions and ensure proper logging or propagation.

// Concurrency
When writing concurrent code, prioritize using utilities from `java.util.concurrent` over raw threads and locks where possible.

// Code Formatting
Ensure all Java files are formatted consistently with 4 spaces for indentation and adhere to the [Google Java Style Guide](google.github.io).
